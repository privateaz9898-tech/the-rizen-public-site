# THE RIZEN — Public Creator Site

Static public website variant derived from the backed-up local framework.

- Uses official external channel and Spotify links.
- Fetches Phoenix weather from Open-Meteo in the visitor browser.
- Keeps Owner Studio, private projects, drafts and browser-local backup data out of the public site.
- Requires a future server/database migration for a shared persistent owner dashboard.

Deploy this directory as the root of a static host.
